# 🛒 SHOPLANE – E-Commerce Web Application

SHOPLANE is a front-end e-commerce web application that allows users to browse products, view product details, add items to a shopping cart, and place orders.
The project is designed to demonstrate core web development concepts using **HTML, CSS, and JavaScript**.

The goal of this project is to simulate a basic online shopping platform and understand how modern e-commerce interfaces work.

# 📖 About the Project

E-commerce websites like Amazon or Flipkart allow users to browse products, add items to their cart, and purchase them online.

This project recreates a **simplified version of an online shopping website** where users can:

* Browse products
* View detailed product information
* Add products to a cart
* Review items in the cart
* Place an order

The project focuses on **frontend functionality and UI interaction** without backend or database integration.

---

# ✨ Features

### 🏠 Home Page

* Displays available products
* Clean product card layout
* Navigation bar with cart icon

### 📦 Product Listing

* Displays multiple products
* Each product shows:

  * Image
  * Name
  * Brand
  * Price

### 🔍 Product Details Page

* Detailed information about selected product
* Larger product image
* Product description
* Price and brand information
* Option to add item to cart

### 🛍️ Shopping Cart

* Displays products added by the user
* Shows quantity and total price
* Allows users to review their order

### ✅ Order Confirmation

* Displays a confirmation message after order placement

### 🎨 UI Components

* Header navigation
* Footer section
* Product cards
* Banner/slider

# 🏗️ Project Architecture

The application follows a **simple modular front-end architecture** where:

* HTML handles the structure
* CSS manages styling and layout
* JavaScript controls dynamic functionality

JavaScript files are responsible for:

* Loading products
* Managing cart data
* Navigating between pages
* Handling user interactions

# ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/shoplane.git
```

### 2️⃣ Open the project folder

```
cd shoplane
```

### 3️⃣ Run the project

Simply open:

```
index.html
```

in any web browser.

No server or backend setup is required.
